Privacy policy

Email Digest Agent accesses Gmail data only for the account of its sole user, the author of this site. It reads messages to build a daily digest, can send that digest to the same account, and moves a message to Spam only when the user clicks to do so.

Message data is stored locally on the user's computer. Message content is sent to OpenAI's API to classify and summarize it; it is not shared with anyone else, sold, or used for advertising.

Contact: open an issue at github.com/jsakowski/jsakowski.github.io.
